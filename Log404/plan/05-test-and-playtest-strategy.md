# 테스트 및 플레이테스트 전략

## 문서 메타
- 목적: 기능 테스트와 유저 플레이테스트 루프를 운영 가능한 형태로 정의한다.
- 독자: 개발자, QA, 테스트 참여자 모집 담당.
- 입력: 코어 루프, 챕터 구조, MVP 완료 기준.
- 출력: 테스트 시나리오, 관측 항목, 개선 루프.

## 기능 테스트 축
- 데이터 로드: JSON 파싱/누락 키 처리
- 진행 로직: 단서 해금, 챕터 해금, 엔딩 분기
- UI 동작: 검색/필터/북마크/보드 상호작용
- 저장/불러오기: 세션 재개 일관성

## 플레이테스트 운영
- 대상: 2~3명 소규모 반복 테스트
- 빈도: 주 1회
- 관측 항목: 막힘 지점, 오해 지점, 피로 지점, 완료 시간

## 난이도 조정 루프
1. 막힘 구간 수집
2. 단서 노출 타이밍 조정
3. 힌트 문구 보강
4. 재테스트로 효과 검증

## 수락 기준
- 첫 플레이에서 핵심 루프 이해 가능
- 힌트 없이도 주요 퍼즐의 절반 이상 해결 가능
- 힌트 사용 시 최종 클리어가 보장될 것
