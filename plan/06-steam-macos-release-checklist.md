# Steam/macOS 출시 체크리스트

## 문서 메타
- 목적: 출시 직전 누락되기 쉬운 플랫폼/스토어 항목을 체크리스트로 고정한다.
- 독자: 릴리스 담당, 개발자.
- 입력: 빌드 산출물, 스토어 자산, 정책 요구사항.
- 출력: 단계별 확인 목록, 완료 판정 기준.

## 빌드 검증
- Windows 빌드 실행/저장/엔딩 분기 확인
- macOS 빌드 실행/저장/엔딩 분기 확인
- 버전 표기 및 빌드 번호 일치 확인

## macOS 요구사항
- 64비트 대상 확인
- 코드 서명 절차 확인
- notarization 제출/검증 완료

## Steam 업로드 준비
- 앱 메타데이터(설명/태그/지원 언어) 정리
- 스크린샷/캡슐 이미지/트레일러 업로드 준비
- 브랜치(테스트/릴리스) 운영 규칙 확인
- 배포 전 내부 QA 빌드 승인

## 선택 기능 점검
- 업적 도입 여부
- Steam Cloud 도입 여부
- Steamworks API 연동 범위(필수/선택) 확인

## 종료 기준
- 두 플랫폼 모두 치명 결함 없이 1회차 완주 가능
- 스토어 자산/문구/버전 정보가 빌드와 일치
- 릴리스 Go/No-Go 체크리스트 100% 완료
