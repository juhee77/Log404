# 세계관과 내러티브 설정

## 문서 메타
- 목적: 사건 배경과 데이터 소스의 서사적 역할을 정의한다.
- 독자: 내러티브 기획, 레벨/콘텐츠 기획, UI 작성 담당.
- 입력: 세계관 톤, 사건 개요, 문서 유형 목록.
- 출력: 배경 설정, 사건 축, 소스별 서사 기능.

## 세계관
- 배경: 근미래 SaaS 기업
- 조직 환경: 협업툴, 배포 시스템, 접근제어, 헬프데스크 운영
- 사건 발단: 핵심 직원 실종, 일부 서버 로그 정리/누락
- 공표 내용: 회사는 "개인 사정 퇴사"로 공지

## 사건 축
- 표면 사건: 단순 퇴사 처리
- 실제 사건: 내부 데이터 조작과 은폐 정황
- 플레이어 역할: 사내 보안 분석가(조사 권한 보유)

## 데이터 소스별 역할
- API/Auth 로그: 행위 시점과 계정 진위
- DB Query 로그: 은닉/삭제 흔적
- 메신저: 인간 관계, 공모 정황
- 이메일: 공식 커뮤니케이션과 책임 회피 패턴
- CCTV 텍스트 리포트: 물리 동선 보강
- 인사 파일: 동기/평가/갈등 배경
- 티켓 시스템: 작업 이력과 서술 충돌 확인
- 상태 대시보드: 사건 당일 이상 징후의 전역 맥락

## 내러티브 원칙
- 과장된 해킹 연출보다 기업 내부 문서의 현실감을 우선한다.
- 악역의 동기는 데이터/행동 기록으로 추론 가능해야 한다.
- 챕터 말미마다 "새 가설"이 열리는 구조를 유지한다.
