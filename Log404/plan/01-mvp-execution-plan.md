# MVP 실행 계획 (6~10주)

## 문서 메타
- 목적: MVP를 실제 구현 가능한 작업 단위로 분해한다.
- 독자: 구현 담당자(1인 개발 기준).
- 입력: MVP 기준 수량, 코어 루프, 기술 스택.
- 출력: 우선순위 백로그, 완료 기준, 주차별 목표.

## 우선순위 백로그
1. 코어 UI 골격(좌/중/우/하단) 구축
2. 로그 뷰어 + 검색/필터/북마크
3. 사건/단서 JSON 로더 및 해금 로직
4. 챕터 1~3 콘텐츠 입력
5. 증거 보드 및 추론 제출 플로우
6. 엔딩 2종 분기 처리
7. 저장/불러오기

## 주차별 권장 흐름
- 1~2주차: UI 프레임 + 로그 뷰어
- 3~4주차: 데이터 연결 + 챕터 진행
- 5~6주차: 퍼즐 밸런싱 + 엔딩 분기
- 7~8주차: 저장/불러오기 + 안정화
- 9~10주차: 버그픽스 + 플레이테스트 반영

## 완료 기준
- MVP 포함 항목이 모두 플레이 가능
- 치명 결함(진행 불가/저장 손상) 0건
- 첫 플레이 60~90분 완주 가능
- 최소 3인 플레이테스트 피드백 반영 완료
