# 기술 스택 결정

## 문서 메타
- 목적: 엔진/도구/배포 파이프라인의 우선 선택을 고정한다.
- 독자: 클라이언트 개발자, 빌드/릴리스 담당.
- 입력: 플랫폼 요구사항, 프로젝트 규모, 개발 인력 조건(1인).
- 출력: 권장 스택, 대안 비교, 운영 방침.

## 1순위 스택
- 엔진: Godot 4.4+
- 언어: GDScript
- 데이터: JSON 기반 콘텐츠 드리븐
- 형상관리: Git + GitHub
- UI 협업: Figma
- 오디오: 엔진 기본 오디오 시스템
- 배포: Steamworks

## 선택 근거
- UI/문서 중심 게임에서 구현 반복 속도가 빠름
- Windows/macOS export 공식 흐름이 비교적 단순
- 콘텐츠 추가 시 코드 수정량 최소화 가능

## 2순위 대안 (Unity)
- 장점: 생태계와 툴 체인 성숙
- 단점: 본 프로젝트 범위(텍스트/도구형 UI 중심)에서 초기 무게가 큼
- 재평가 조건: 3D 탐색, 컷신, 고연출 비중 확대 시

## CI/CD 및 운영
- 초반: 수동 빌드/수동 검증
- 중후반: GitHub Actions로 빌드 자동화 도입
- 분석: 초기에는 내부 텍스트 로그만 수집, 외부 툴은 출시 후 판단

## 참조 자료
- Steam 플랫폼/SDK 문서
- Godot Export 문서
- Unity macOS 빌드 문서
