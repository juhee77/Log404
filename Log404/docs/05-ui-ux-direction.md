# UI/UX 방향성

## 문서 메타
- 목적: 화면 구조와 톤앤매너를 고정해 아트/개발 해석 차이를 줄인다.
- 독자: UI 디자이너, 프론트엔드 구현 담당, 기획/QA.
- 입력: 레퍼런스 무드, 코어 플레이 루프, 화면 요구사항.
- 출력: 레이아웃 규격, 화면 목록, 인터랙션 원칙.

## 기본 레이아웃
- 좌측: 사건 목록, 폴더 트리, 문서 네비게이션
- 중앙: 현재 열람 콘텐츠(로그/메일/채팅/리포트)
- 우측: 단서 패널, 북마크, 용의자 정보
- 하단: 검색창, 필터, 시간축, 명령 입력

## 화면 목록
- 로그인
- 사건 대시보드
- 로그 뷰어
- 메일/채팅 뷰어
- 증거 보드
- 최종 보고서 작성

## 톤앤매너
- 다크 테마 기반의 건조한 업무 도구 느낌
- 포인트 컬러는 청록/시안 계열로 제한
- 로그 영역은 모노스페이스 폰트 사용
- 과도한 글로우/글리치/해킹 애니메이션 금지

## 인터랙션 원칙
- 클릭 가능 포인트를 명확한 상태 변화로 표시
- 강조 색상은 핵심 수치/의심 라인에만 사용
- 텍스트 밀도는 높게 유지하되 줄간격/구획으로 피로 최소화
- 탐색 행동(검색/필터/북마크)이 추리 진행과 직접 연결되어야 함

## 레퍼런스 활용 가이드
- 외형 복제 금지, 정보 구조와 밀도 설계 방식만 차용
- "예쁜 UI"보다 "설득력 있는 사내 도구"를 우선
