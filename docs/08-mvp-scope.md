# MVP 범위 기준 (단일 기준 문서)

## 문서 메타
- 목적: MVP 수량/범위를 단일 기준으로 고정해 문서 간 충돌을 방지한다.
- 독자: 전 팀 공통.
- 입력: 초기 기획 범위, 개발 기간, 1인 개발 제약.
- 출력: 필수 포함 항목, 제외 항목, 변경 통제 규칙.

## 목표
- 첫 완주 가능한 사건 경험 제공
- 플레이타임: 60~90분
- 품질 기준: 핵심 루프 재미 검증 가능 수준

## MVP 포함 항목
- 사건: 1개
- 챕터: 3개
- 로그 종류: 3개
- 메일 스레드: 4개
- 채팅방: 2개
- 증거 보드: 1세트
- 엔딩: 2개

## MVP 제외 항목 (초기)
- Steam 업적
- Steam 클라우드 저장
- 다국어 지원
- 고퀄 시네마틱/컷신
- 외부 분석 SDK

## 변경 통제 규칙
- 수량 변경은 본 문서를 먼저 수정하고, 연계 문서를 후속 갱신한다.
- 관련 문서: `docs/*`, `plan/*`
- 기준일: 2026-04-04
