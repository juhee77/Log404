# 📱 나만의 만화책 & 가챠 보관함 (Pocket Shelf APK) 기획서

## 1. 프로젝트 개요
- **프로젝트명**: `game02` — **주희의 포켓 북쉘프 & 가챠 보관함 (Pocket Shelf APK)**
- **플랫폼**: 모바일 APK / PWA 하이브리드 앱 (LocalStorage + JSON 백업 + WebRTC 카메라 + Google Books API)
- **핵심 가치**:
  1. **🌐 웹에서 표지 긁어오기**: 도서/만화 제목 검색(Google Books API + 추천 만화 카탈로그) 및 이미지 URL 직접 입력으로 실제 단행본 표지를 1초 만에 내 책장에 꽂기
  2. **📸 자동 카메라 촬영 입력**: 카메라 탭 진입 시 자동으로 카메라(`getUserMedia`)가 켜지며, 단행본(2:3) 또는 가챠 아크릴(1:1) 가이드 프레임에 맞춰 촬영 즉시 표지/피규어로 등록
  3. **🎨 나만의 책 만들기 공방 (DIY Book Maker)**: 표지 레이아웃 템플릿 5종, 만화책 하단 **띠지(Obi / 오비)** 문구·컬러 커스텀, 특수 코팅(`🌈 홀로그램`, `👑 초판 골드박`, `✨ 프리즘`), 초판 스티커 부착
  4. **📖 권별(1권~N권) 다이어리**: 책을 펼치면 권마다 개별 표지, 소장 상태(`소장완료`/`초판특전`/`읽는중`/`위시`), 별점, 명대사, 독서 노트를 로컬에 영구 기록
