## 🗺️ 매장 구조

매장 전체가 **하나의 연속된 아이소메트릭 평면도**입니다. 10×8칸 바닥을 세 구역이
나눠 쓰고, 경계에는 출입구가 뚫린 칸막이벽이 섭니다.

| 구역 | 칸 | 내용 |
| :-- | :-- | :-- |
| 📖 열공방 | (0,2)–(5,7) | 책상 배치 구역 (6×6 = 36칸) |
| ☕ 라운지 | (6,0)–(9,3) | 커피바, 칠판 메뉴, 라운지 테이블 |
| 🔑 프런트 | (6,4)–(9,7) | 무인 키오스크, 스마트 사물함 8칸, 출입 게이트 |

방 껍데기도 아이소메트릭입니다. 바닥 마름모의 뒤쪽 두 변에서 벽면이 올라가고,
그 위의 걸레받이·웨인스코팅·창·문이 모두 바닥과 같은 투영을 공유합니다.
**문은 실제로 여닫힙니다** — 손님이 드나드는 동안 경첩을 축으로 방 안쪽으로
열리고, 문틈으로 바닥에 빛이 번집니다.

### 층별 성격
- **1F** 원목 슬랫 벽 + 오크 마루, 앰버 간접등
- **2F** 딥 버건디 벽에 골드 픽처레일·웨인스코팅, 카펫 바닥, 프라이빗 부스
- **3F** 실내가 아닌 옥상. 시간대별 하늘, 도시 스카이라인, 유리 난간, 스트링
  전구, 파라솔 딸린 야외 테라스 테이블

층마다 자기 좌석만 보입니다. 1층은 기본 좌석을, 해금된 위층이 6석씩 나눠 갖습니다.

## 🔨 책상 배치

꾸미기 모드에서 책상을 클릭해 잡은 뒤, 원하는 칸을 클릭하거나 끌어서 놓습니다.

- 아이소메트릭 격자에 자석처럼 흡착하고, **두 책상이 한 칸에 겹치지 않습니다**.
  이미 찬 칸에 놓으면 가장 가까운 빈 칸으로 밀려납니다.
- 드래그 중 착지 위치가 미리보기로 표시됩니다 (초록=가능, 빨강=이미 참).
- 층이 다르면 같은 칸을 써도 됩니다.
- 배치는 저장되며, `↺ 배치 초기화` 로 기본 배치로 되돌릴 수 있습니다.
- 기본 배치는 새 책상을 "이미 놓인 책상들로부터 가장 먼 빈 칸"에 배정해,
  좌석이 몇 개든 방 전체에 고르게 퍼집니다.

## 📜 메인 스토리 — 「등대 독서실」

5막 32단계. 각 퀘스트는 실제 행동(로스팅·베이킹·청소·서빙·캐스팅·소품 배치·
책상 재배치 등)과 1:1로 묶여 있어, 해당 행동을 했을 때만 진행됩니다.

| 막 | 내용 |
| :-- | :-- |
| 🕯️ 1막 불을 다시 켜다 | 첫 로스팅, 청소, 책상 배치, 첫 손님 |
| ☕ 2막 단골이 생기다 | 바리스타 민서 합류, 소품·칸막이, 나비, 좌석 확장 |
| 🏢 3막 길 건너 포커스존 | 24시간 프랜차이즈와의 경쟁, 평점 회복 |
| 🔑 4막 2층, 노블리스 | 1인실, 시그니처 원두로 차별화 |
| 🌇 5막 루프탑, 그리고 D-DAY | 수능 시즌, 야식, 누적 손님 100명, 엔딩 |

막이 바뀌면 매장이 어두워지고 장면 카드가 떠올라, 그 막에서 문을 열고 들어오는
인물의 대사를 보여줍니다.

## 👥 손님

네 가지 타입이 각자 소지품을 들고 옵니다 — 🎓 고등학생(교복 책가방),
📚 공시생(수험서 3권 + 텀블러), 💻 개발자(노트북 슬리브 + 헤드폰),
☕ 재택 직장인(서류 트레이 + 텀블러).

평판이 높을수록 이름 있는 단골(수현·민준·현우)이 다시 찾아옵니다. 단골은
머리 위에 이름표가 붙고, 공부를 마치고 갈 때마다 친밀도가 쌓입니다.

손님은 출입 게이트로 들어와 커피바 카운터에 들렀다가 자리로 갑니다. 카운터에서
주문하면 실제 베이커리 재고가 줄어듭니다.

## ☕ 핸드드립 추출 미니게임

공부하던 손님이 음료를 주문하면 커피바를 눌러 직접 내립니다.
**뜸들이기 → 1차 추출 → 2차 추출** 3단계를 타이밍으로 맞춥니다. 단계마다
게이지가 점점 빨라지고 목표 구간은 좁아집니다 (20% → 15% → 12%).

| 결과 | 팁 배율 | 평점 |
| :-- | --: | --: |
| PERFECT (3/3) | ×2.5 | +0.12 |
| GOOD (2/3) | ×1.6 | +0.05 |
| 보통 (1/3) | ×1.2 | — |
| 실패 (0/3) | ×0.8 | −0.04 |

클릭 또는 `Space` 로 멈춥니다.
