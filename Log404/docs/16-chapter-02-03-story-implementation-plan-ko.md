# 챕터 2-3 서사 구현 계획

## 목적
- MVP 3챕터 구조에서 현재 구현된 챕터 1 다음 흐름을 문서 기준으로 고정한다.
- `다음 스토리`는 챕터 2 `도와주는 사람의 손길`, `다다음 스토리`는 챕터 3 `존스는 너무 쉽게 미워진다`로 정의한다.
- 웹 조사 화면이 단순 단서 진행률이 아니라 현재/다음/다다음 서사를 함께 보여주도록 연결한다.

## 챕터 2 구현 방향
- 서사 목표: 앨리스가 실제로 플레이어를 도와주며 신뢰를 강화하지만, 존스에게 불리한 정황만 빠르게 건네는 패턴을 심는다.
- 감정 목표: 안도, 의존, 미세한 불편함.
- 데이터 근거:
  - `log_badge_gap`
  - `log_auth_midnight`
  - `log_jones_calls`
  - `note_if_i_disappear`
- 화면 목표:
  - 브리핑에서 앨리스의 도움과 그 불균형을 동시에 보여준다.
  - 서사 진행선에서 플레이어가 "지금은 신뢰가 쌓이는 장"에 있음을 체감하게 한다.

## 챕터 3 구현 방향
- 서사 목표: 존스를 유력 용의자로 몰아가되, 모든 증거가 너무 매끈하게 정리돼 있다는 불편함을 만든다.
- 감정 목표: 확신, 분노, 찜찜함.
- 데이터 근거:
  - `log_alice_dm_read`
  - `log_alice_vpn_rewrite`
  - `mail_alice_to_player`
- 화면 목표:
  - 조사 화면에서 현재 챕터 목표와 다음 의심 전환점을 명시한다.
  - 플레이어가 "존스가 범인처럼 보이지만 누군가 그 방향을 설계했다"는 질문을 갖게 한다.

## 구현 항목
1. `data/story/chapter_02`, `data/story/chapter_03` 콘텐츠 팩 추가
2. 엔진이 챕터 콘텐츠 팩과 시즌 감정 아크를 읽도록 확장
3. 웹 스냅샷에 현재 챕터 브리프와 현재/다음/다다음 서사 진행선 추가
4. 웹 화면에 서사 진행선 패널 렌더링
5. 챕터 서사 노출 회귀 테스트 추가
