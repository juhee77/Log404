# 마스터 로드맵 (0~4단계)

## 문서 메타
- 목적: 전체 일정을 단계별로 고정하고 진입/종료 조건을 명확히 한다.
- 독자: 프로젝트 오너, 개발자, 협업자.
- 입력: 제품 목표, MVP 범위, 플랫폼 요구사항.
- 출력: 단계별 기간, 마일스톤, 의존성.

## 전체 일정
- 0단계 목표 고정: 2~3일
- 1단계 프로토타입: 2주
- 2단계 수직 슬라이스: 3~4주
- 3단계 본편 제작: 6~10주
- 4단계 마감/출시 준비: 3~4주

## 단계별 마일스톤
- M0: 범위 문서 동결 및 퍼즐 목록 확정
- M1: 로그 뷰어 + 검색 + 북마크 동작
- M2: 15~20분 데모 플레이 가능
- M3: 전체 챕터/엔딩/저장 기능 완성
- M4: Steam 업로드 준비 완료

## 진입/종료 조건
- 각 단계 진입 전: 이전 단계 산출물 리뷰 완료
- 각 단계 종료: 최소 1회 플레이테스트와 결함 triage 완료

## 의존성
- 콘텐츠 제작은 데이터 스키마 확정 이후 진행
- 플랫폼 검증은 저장/불러오기 안정화 이후 진행
